# PROJECT-NAS System Definition

PROJECT-NAS is a personal operating system for knowledge, capability, execution, AI-assisted work, and continuous improvement.

## Core domains
- Knowledge
- Skills
- AI
- Operations
- Standards
- Security
- Validation
- Integrations

## Authority hierarchy
1. Approved PROJECT-NAS standards
2. Current canonical artifacts
3. External references
4. Drafts and experiments

## Canonical-source rule
Each concept has one authoritative source. Derived views must identify their source and must not silently diverge.

## Lifecycle
Artifacts use: `draft`, `active`, `deprecated`, `archived`.

## Design principle
Build the operating model before the interface. Prefer deterministic validation and technology-light foundations.
