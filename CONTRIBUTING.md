# Contributing to PROJECT-NAS

## Before changing anything
Read `AGENTS.md`, `PROJECT-NAS.md`, and the relevant standard under `docs/standards/`.

## Workflow
1. Inspect the current state.
2. Define the smallest useful change.
3. Make the change.
4. Run validation.
5. Review the diff.
6. Commit with a clear message.

## Quality gate
A change is not complete until applicable validation passes and the final state is understood.

## Canonical content
Do not duplicate authoritative material. Link to the canonical artifact instead.
