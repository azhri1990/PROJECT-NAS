# PROJECT-NAS Agent Operating Rules

## Mission
PROJECT-NAS is a personal operating system for knowledge, capability, execution, AI-assisted work, and continuous improvement.

## Non-negotiable rules
1. Inspect before changing.
2. Preserve useful existing work.
3. Prefer simple, inspectable formats.
4. One canonical source per concept.
5. Do not introduce frameworks or dependencies without a concrete requirement.
6. Never commit secrets, credentials, private keys, tokens, or sensitive personal data.
7. Validate changes before claiming completion.
8. Authoritative standards outrank drafts and external references.
9. Record significant architectural decisions.
10. Do not create empty directories merely for symmetry.

## Change workflow
Inspect -> plan -> change -> validate -> review diff -> commit.

## Authority
Authoritative standards live under `docs/standards/`. Approved decisions live under `docs/decisions/`. External references are evidence, not authority by themselves.
